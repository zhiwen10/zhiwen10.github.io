# General procedures

Rules that apply to all experiments:

- Raw data is **read-only** — processing writes derived data elsewhere
- Record metadata for every session: date, person, setup, code version (git commit hash)
- Data goes to the [data server](data-server.md), never only on a local machine, and is covered by the [backup policy](data-backup.md)
- Follow the relevant [protocol](protocols.md) for your experiment; deviations must be approved by {{PI_NAME}}
- {{GENERAL_NOTES}} — lab-specific rules (sign-up sheets, rig booking, etc.)
