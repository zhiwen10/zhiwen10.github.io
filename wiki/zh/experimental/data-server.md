# 数据服务器

实验数据存放在实验室服务器上，不在 git 中，也不（只）在本地机器上。

## 服务器

| 服务器 | 挂载 / 路径 | 用途 |
|---|---|---|
| {{SERVER_1}} | {{DATA_PATH}} | 原始数据 + 派生数据 |
| {{SERVER_2}} | {{PATH}} | {{PURPOSE}} |

服务器硬件与访问方式：参见[实验室电脑](../the-lab/computers.md)。

## 目录结构与约定

- 原始数据为**只读**。数据处理产生的派生数据写入单独的位置
- 每个数据集目录都配有一个简短的 `README.md`：来源、日期、格式、生成者
- 命名规范：{{DATA_NAMING}} —— 实验 / 运行批次的命名约定
- 数据存放在 {{DATA_PATH}} 中，绝不放入 git —— Gitee 仓库有大小限制

备份：参见[数据备份](data-backup.md)。
