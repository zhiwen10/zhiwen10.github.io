## Gitee 组织

实验室的代码托管在 Gitee 的 **ye-lab** 组织下：https://gitee.com/ye-lab；或 https://edu.gitee.com/ye-lab。
这两个网站使用相同的后端，但前端界面不同。
我们使用的是教育免费版（edu.gitee.com/ye-lab）。
企业版（gitee.com/ye-lab）通常收费每人 400–500 元人民币，因此我们捡了个便宜。

获取访问权限的步骤：

1. 在 https://gitee.com 注册个人 Gitee 账号
2. 随后我会通过飞书或邮件向你发送邀请链接，以加入该团队（ye-lab）
3. 你将以团队成员身份加入该组织，通常为管理员（admin）
4. 安装 Git 并将其连接至 Gitee — 参见 [Git 与 Gitee 使用规范](../code/git-gitee.md)

> 为什么选择 Gitee 而非 GitHub？在某些实验室地点/网络下无法访问 GitHub。Gitee 是实验室的主要平台；部分精选仓库会同步镜像到 GitHub 以提升国际可见度。参见 [Git 与 Gitee 使用规范](../code/git-gitee.md)。
