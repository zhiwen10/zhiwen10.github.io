## Gitee 组织

实验室代码托管在 Gitee 的 **ye-lab** 组织下：https://gitee.com/ye-lab；或 https://edu.gitee.com/ye-lab。
这两个站点共享同一后端，但前端界面不同。
我们使用的是免费教育版（edu.gitee.com/ye-lab）。
企业版（gitee.com/ye-lab）通常每人需支付 400–500 元人民币，因此我们采用了教育版这一优惠方案。

获取权限步骤：

1. 在 https://gitee.com 注册个人 Gitee 账号
2. 随后我会通过飞书或邮件向你发送加入（ye-lab）群组的邀请链接
3. 你将被添加为该组织的团队成员，通常拥有管理员权限
4. 安装 Git 并将其连接至 Gitee —— 参见 [Git 与 Gitee 使用规范](../code/git-gitee.md)

> 为什么选择 Gitee 而非 GitHub？部分实验室地点 / 网络无法访问 GitHub。Gitee 是实验室的主要平台；部分仓库会镜像至 GitHub 以提高国际可见度。参见 [Git 与 Gitee 使用规范](../code/git-gitee.md)。
